# soft-tech-portfogen

No-code portfolio maker. Plain HTML/CSS/JS, no build step.

## Features

- Generate portfolios without writing code
- Uses plain HTML, CSS, and JavaScript
- No complex build steps or bundlers required

## Getting Started

To run the application locally:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

## Testing

Run all tests:
```bash
npm test
```

Run specific tests:
- Render tests: `npm run test:render`
- UI smoke tests: `npm run test:ui`
